# Growth and conversion notes

## Positioning

EarnLoop is a **workshop**, not a casino. Copy and motion should make effort visible: checklists, proofs, hours, loops closed.

## High-converting patterns we will implement

| Pattern | EarnLoop application |
| --- | --- |
| Single primary CTA | `Start a loop` → `/earn?capital=0` or last viewed hustle |
| Bento product preview | Hero dashboard mock wired to demo data, then live for members |
| Intent URLs | `/earn?capital=0`, `/earn?difficulty=easy`, `/pricing` |
| Interactive demo | Checklist on a sample hustle without account; save requires login |
| Pricing transparency | Free vs Loop+ vs credits vs services, no “contact us” for core plans |
| Sticky mobile CTA | After 60% scroll |
| Personalized hero (light) | If `?ref=` or last filter cookie, swap subheadline |
| Social proof | Real weekly loops + anonymized proof titles |
| Shareable OG | Each hustle as a growth unit |
| Freemium that teaches | First steps free; prompts that *ship* gated |
| Habit → pay | Streak freeze + extra credits, not pay-to-win XP |

## Navbar merchandising

- **Learn** = trust and SEO.  
- **Earn** = core loop (directory).  
- **Tools** = daily habit / credit sink.  
- **Services** = high AOV when logged in.  
- **News** = AdSense + returning traffic.

## Ads policy (practical)

- Don’t promise income in H1 next to ads.  
- Label ads.  
- Don’t inject ads into the checklist itself.  
- Loop+ can hide ads (`hide_ads_for_plus`).

## Launch content

Seed 8–12 original hustles covering $0 content, print-on-demand, freelance design, local AI receptionist, newsletter, mini-SaaS idea, tutoring, Etsy printables. Human-edit all AI drafts.

## KPIs for admin Overview

Sessions, signup rate from Start a loop, tool runs, credit burn, publish cadence, AdSense (manual until API), orders by status.
